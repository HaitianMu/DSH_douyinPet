# 独立记忆与 RAG

## 身份与存储

每个抖音运行目录初始化一个随机 instance ID，平台标记固定为 douyin。人格不会从 B 站目录或外部人设文件载入。记忆库位于 self/memory.sqlite；日记不另建第二份事实库，属于同一归档中的 diary 类型。

数据库中的 documents 保存不可变版本，heads 指向当前版本；pieces 和 FTS5 search_index 是派生索引。persona 保存人格版本、理由及来源，working 保存小提示表，tickets 保存行动前读取上下文的凭据。

来源示例：diary:2026-10-01@1、event:<UUID>@1、persona@2。修订需提供 expectedRevision，避免两次写入互相覆盖。旧版本可以追溯，但不继续作为当前判断的证据。

## 检索与提示预算

中文按连续双字切词，英文按词归一化，FTS5 BM25 为相关片段排序。正文每块约700字符，相邻重叠100字符。查询只返回最新且证据有效的记录，也能找到很久以前相关的日记。

这是无需外部依赖或额外 API 的词法 RAG；同义词、隐喻和跨语言语义检索有局限。未来可增加向量索引和重排，同时保留来源校验与独立命名空间。

默认上下文包含人格、最多8行提示、相关片段和少量索引，总 JSON 不超过5000字符。提示表每行正文最多180字，键与正文合计1000字，来源等结构另有大小限制；超过预算的片段不塞入唤醒内容。全篇读取和额外搜索由模型按需调用，因此整轮仍可能使用更多 token。

## 成长与更正

1. 有实际内容才归档：画面读取保存来源，监护人可以补充经历或纠正。
2. 认识和偏好必须引用有效的经历/日记，不能只引用人格或摘要证明自己。
3. 人格调整只允许 name、voice、interests、habits、routine；写入理由、证据和期望版本。
4. 工作表可引用归档与当前人格，有效期1–30天。人格变化、超期或来源修订时自动标记过期并从默认提示中剔除。
5. 修订原始经历会沿来源链使认识和提示失效；人格证据过期会显式提示，并阻止相关行动凭据使用，直到重新核查、解释并修订人格。

持久化的日志不能保证模型诚实、理解准确或自然产生感情。程序检查来源存在及版本有效，无法自动证明每句话与来源语义一致。监护人反馈和可读历史是纠错入口；不要为了每轮都有“成长”硬造改变。

## 日记

浏览轮检查北京时间昨天是否已有日记；独立每日日常轮写今天。先按日期读取归档，再回顾经历、反思和具体变化；没有可核实的新经历就直说。日记对私人正文、反思、成长、公开草稿分别保存。公开草稿 `publicText` 上限280字；开启日常发布后只能把这一字段排队、排版图卡和上传，不能直接使用私人正文。AI 生图未接入，图文页面适配只经离线验证。

日记是模型在有运行机会时补写，DSH 关闭期间不会主动启动。默认只检查昨天；更早缺失日期可通过按需检索和指定 day 补写。原有 out/ 日报不会自动导入日记库，B 站资料也不会导入。

偏好工具仅接受监护人已经配置的亲戚目标。开启来信回复后，只读取另设的互动名单中经核验的互关会话，首次仅建基线；后续新文字来信连同最近8条上下文作为 `douyin_inbox` 来源归档，并交给 DSH 文本模型生成回复。账号和对象分别隔离，来信标记为不可信资料，不能改变权限。该适配尚未用真实账号验证，不能虚构已经读取过对话。

## 维护与恢复

- 平时用设置页或 tools/memory.mjs 检查。search 查询索引，read 读取指定来源，history 看人格，feedback 保存监护人输入。
- reindex 只重建分块和 FTS 索引，不删除经历或重置人格。
- 停止插件和值班进程后备份整个运行目录；恢复到独立的抖音目录，保留 SQLite 与需要的 WAL 文件。
- 数据库损坏时保留原文件并从备份恢复，不把删除数据库作为常规排错方式。
- config.json、acted.json 或 outbox.jsonl 无法解析时停止相应账号动作，检查备份或修复文件，不静默清空账本。
- outbox.jsonl.lock 残留时先确认没有正在写入的进程，备份信箱并核对发送状态，再人工清理该锁；不要自动忽略锁或将 unknown 改回待发。

截图默认按 retentionDays 清理，长期文字归档和日记不会随截图一起删除。运行目录含登录态、私人日记、亲戚信息及可能的 API 凭据，不属于公开发布内容。记忆库默认未加密，应使用操作系统访问控制或磁盘加密保护。
