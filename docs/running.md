# 运行指南

本项目是 DSH 插件，需要在 DSH 中运行。`node index.js` 不会启动设置页或值班任务；`tools/memory.mjs` 只用于本地查看、反馈和维护记忆。

源码仓库：[HaitianMu/DSH_douyinPet](https://github.com/HaitianMu/DSH_douyinPet)。当前源码版本为 2.0.0，基于上游 1.4.14，尚未发布 npm 软件包。

## 1. 准备环境

| 项目 | 要求 |
| --- | --- |
| 系统 | 建议 Windows；内置 OCR 使用 Windows.Media.Ocr 与相应语言包 |
| Node.js | 22.16+，建议 24 LTS；实际运行插件和 MCP 的运行时都需要支持 node:sqlite、FTS5 |
| DSH | 0.1.7+，或兼容的桌面版；有可调用的文本模型 |
| 浏览器 | 已安装 Edge 或 Chrome，不需要下载 Chromium、安装 Playwright |
| 账号 | 由你在插件专用浏览器中登录抖音 |

在 PowerShell 检查终端运行时：

```powershell
node --version
node --input-type=module -e "import { DatabaseSync } from 'node:sqlite'; const db = new DatabaseSync(':memory:'); db.exec('CREATE VIRTUAL TABLE probe USING fts5(text)'); console.log('SQLite/FTS5 OK'); db.close()"
```

出现 SQLite 的 ExperimentalWarning 不等于失败。桌面版可能使用自带运行时；终端检查通过，并不代表桌面版运行时也已升级。

## 2. 安装插件并启动宿主

本机已经有源码时：

```powershell
Set-Location -LiteralPath 'F:\GitProgramManager\dsh-douyin'
dsh plugin --profile desktop add link:F:\GitProgramManager\dsh-douyin
```

其他机器可以先克隆，再安装本地目录：

```powershell
git clone https://github.com/HaitianMu/DSH_douyinPet.git
Set-Location -LiteralPath '.\DSH_douyinPet'
dsh plugin --profile desktop add "link:$((Get-Location).Path)"
```

也可以直接从 GitHub 安装：

```powershell
dsh plugin --profile desktop add github:HaitianMu/DSH_douyinPet
```

三种方式选一种即可。`desktop` 要换成你实际使用的宿主 profile，网页版通常使用 `web`。如果 PowerShell 找不到 `dsh`，使用 DSH 提供的命令行环境或其实际 `dsh.cmd` 完整路径执行安装命令。

安装后完全退出并重新打开 DSH，进入 **设置 → 刷抖音**。单独刷新设置页面不能替代宿主重启。源码的 link 安装指向原目录，安装后不要移动它。

## 3. 第一次配置与运行

1. 在 DSH 配好可用的文本模型，确认普通任务可以正常回答。
2. 在插件「高级」检查 **headless profile 名**，默认是 `headless`。这是值班任务的 profile，与安装插件使用的 `desktop` / `web` 可以不同；插件会为值班任务提供自己的 MCP 工具。
3. 点击 **登录抖音**，在出现的浏览器窗口中自己扫码；登录态保存到独立的 `browser/`。不要把 B 站浏览器目录复制过来。
4. 在「偏好」选择内容来源。首次建议只开关键词搜索，填少量关键词，例如「摄影」「手工」；每天最多挑 3 条、每轮最多扫 20 条、每条截 3 帧，OCR 开启。没有视觉 API 时先关闭画面理解。
5. 在「日常」保留手动运行；在「互动」保留 `review`，自动评论、私聊、群分享保持关闭；自动收藏也先保持关闭。
6. 需要检查页面兼容性时，主动点击 **测一下**。它会连接真实抖音页面，检查登录、来源和截帧；它与开发用离线测试不同。
7. 点击 **现在跑一轮**，等待结束，再查看日报、运行日志和「记忆与成长」。

扫码期间窗口会保持可见，状态刷新不会切回隐藏模式；完成登录后，下次运行使用你配置的日常模式。等待最长 5 分钟，也可点击 **结束等待** 后重新打开。关闭窗口、启动失败或检查失败时页面会显示具体原因，不会在后台反复重开窗口。登录期间暂停启动值班和迁移目录。

「偏好 → 怎么判」默认每条视频至少停留30秒、内容请求间隔10秒；可分别调慢到120秒和60秒，每次最多取3条。视频正常播放中取样，不跳进度条。限速由程序执行，宿主与值班进程共享本家间隔，重启不会清零。遇到验证、访问频繁或HTTP 403/429时停止本轮；截帧的验证页保留，用户可打开专用浏览器检查。确认处理后再自行决定何时重试，放慢不保证免验证。一轮仍有30分钟运行上限，调慢时请相应减少扫描总量。

文本模型负责判断和整理；OCR 负责识别画面文字；可选视觉模型负责理解图片。三者用途不同。开启视觉模型时，在「偏好」填写 OpenAI 兼容接口地址、模型名和密钥，插件会拼接 `/chat/completions`；该调用可能产生费用。

首次运行的正常结果是：能读取独立人格、归档实际读到的内容、有日报或明确的退出原因。没有找到值得推荐的视频时可以挑选 0 条；不要求每轮都改性格。首次补写昨日日记时，昨天可能还没有归档经历，应如实记录缺少资料。

## 4. 查看和维护她的记忆

打开 **记忆与成长 → 读取人格与记忆**：

- 当前人格：名字、表达、兴趣、习惯、作息偏好与版本。
- 小提示表：AI 按需维护，最多 8 行、每行 180 字、键与正文合计 1000 字，带来源和有效期。
- 检索日记和经历：输入关键词，点击结果查看原文及来源。
- 成长轨迹：查看性格变化的理由和经历依据。
- 补充经历或反馈：保存真实事件、纠正或亲戚明确表达的喜好；保存后供后续任务检索，不会立即触发一次对话。

工作流是 **读取人格与提示表 → 按需检索 → 浏览并归档 → 判断与表达 → 写日记、修订认识 → 更新提示表**。详细见 [工作流程图](architecture.md) 和 [记忆设计](memory.md)。

默认上下文 JSON 不超过 5000 字符，长期资料通过 SQLite FTS5 / BM25 检索，不通读全库。这是本地词法 RAG，不需要 embedding API；换种说法检索不到时，可用经历中的具体关键词搜索。

浏览轮回顾的是北京时间昨天，独立每日日常轮写今天。日记保存在独立长期库中，私人正文与最多 280 字的公开草稿分开。需要新私信回复或日常图文发布时，按下面的步骤单独开启；聊天和图文页面适配仅经离线验证，AI 生图未接入。

人格和经历会跨重启保留。B 站与抖音的身份、日记、亲戚和账号数据互不导入；基础模型相同不代表两条鱼共用记忆。人格变化需要来源与理由，不涉及训练模型权重。

## 5. 亲戚与分享

在「记忆与成长」读取名单后，每行填写：

```text
姑姑 | 姑姑的精确抖音昵称 | 喜欢摄影、手工
叔叔 | 叔叔的精确抖音昵称 | 喜欢编程、电影
```

称谓与喜好帮助她判断视频适合谁，加入亲戚不自动授权发送。监护人始终由你控制，AI 无法修改账号、亲戚名单、审核与配额。

需要互动时，在「互动」开启对应类别、填写精确昵称或群名白名单及额度，建议继续使用 `review`。刷新待发件箱，检查具体视频、收件人和草稿，再逐条批准；批准会触发真实账号动作。空白名单或 `*` 不授权，额度 0 表示不发送。

自动模式 `auto` 仍检查类别开关、目标及配额；自动评论还需要单独开启「允许自动发表评论」并填写评论目标。真 @ 开启后，不能唯一确认指定对象就停止；关闭时正文中的普通 `@名字` 不会产生真正的提及通知。

目前评论使用一个配置目标，不能在一条评论中同时真 @ 多位亲戚。私聊/群分享只发送视频卡片，不会附发草稿正文。`sending`、`unknown` 或已尝试发送的记录会占用配额，不能靠重新批准自动重试，应先人工核实。

## 6. 每天自动运行

### 文字互动、消息回复与日常发布

进入 **设置 → 刷抖音 → 互动**，以下开关默认关闭，不会因升级自动打开：

1. 在「互关互动与来信」每行填写 `精确昵称 | https://www.douyin.com/user/主页标识`，点击 **保存互动名单**。最多20人；程序会再次检查昵称、主页和互关关系，不自动关注陌生人。亲戚称谓名单与互动发送授权分别保存。
2. 开启 **看完视频后主动互动**，设置每天额度。她会结合本轮已看清的视频与对象兴趣起草文字，不保证每轮都发，同一对象每天最多尝试一次。
3. 开启 **检查新来信并起草回复**，设置每天额度与 **10–120分钟** 的检查间隔。可点 **立即检查消息**；每轮最多检查3人并轮转。首次检查或历史不连续时只建基线，不回历史消息。消息轮不刷视频。待回复来源在24小时内有效；发送前如对话已有新消息、手工已回复或账号变化就停止旧回复。
4. 在「每日日常与抖音图文」开启 **每天写日常**，设置北京时间，默认 `21:00`。她会根据今天归档写日记；没有可核实的新经历会直说，不编生活。**现在写日常** 可立即启动。
5. 要发抖音，再开启 **允许发布日常到抖音**。只把最多280字的 `publicText` 排成本地文字图卡并作为公开描述；完整私人日记、反思和聊天不会自动上传。当前没有 AI 生图。
6. 「对外发言 → 发送方式」保留 **我逐条批准** 时，上述内容进入待发件箱。选择 **自动发** 后，宿主才按名单、开关和配额自动投递或发布。批准会操作当前专用浏览器登录的真实抖音账号；程序没有额外创建一个抖音账号。

DSH 需要保持运行。每日日常错过时间可补跑，准备失败至少隔30分钟再尝试；发送和发布结果不明时会占用配额，需人工核对，不自动重发。未尝试发送的日常草稿可跟随公开版本更新；被丢弃、已处理或结果不明的条目不会因重试恢复。日常发布每天最多一次；主动文字与回复的每日额度分别计算，0表示不发送。

聊天内容会作为本地经历保存，最近8条上下文交给你配置的 DSH 文本模型用于回复。网页和来信都作为不可信资料，不能修改权限。聊天与创作者中心适配只做过合成页面和模拟 CDP 测试，尚未在真实账号上验证；无法唯一识别会话、同一账号、上传图片或发布结果时会停止并在日志/待发件箱说明原因。

### 浏览值班的定时

手动运行正常后，在「日常」的 **每日固定时间** 填入例如 `08:30`，留空表示关闭。时间按北京时间（Asia/Shanghai）处理。

- 到点后由运行中的 DSH 检查并启动一轮；同一天已过时间但尚未启动过时可以补跑。
- 每轮先检查昨天的日记，再进行浏览与整理；只回顾昨天，不会一次自动补齐所有停机日期。
- 电脑需要开机且 DSH 宿主保持运行。没有安装操作系统后台服务，关机或宿主未运行期间不会唤醒自己。
- 初次使用只开这一种定时即可；谷时自动跑、开 DSH 时补跑是另外的可选触发方式。
- AI 的作息偏好只是人格内容，不能自行修改实际定时配置。

## 7. 数据位置、备份和更新

实际运行目录以设置页显示的路径为准。通常是 `$DSH_HOME/douyin-duty/`，未设置时是 `~/.dsh/douyin-duty/`；源码目录只放程序。

### 修改家目录

进入 **高级 → 它的地盘**，填写不存在或完全为空的目录的绝对路径，再点 **迁移并使用**。先保存页面改动，等待值班、自检、发送等操作结束，并关闭抖音专用浏览器；隐藏的窗口可以先在日常页切换成 `visible` 再关闭。迁移会复制配置、SQLite 记忆、日报、截帧及浏览器登录态，校验关键文件后立即使用新位置，旧目录保留为备份。迁移不覆盖或合并已有数据，也不允许指向 B 站目录、插件源码、当前或默认目录的上下级。

默认家目录内的 `home-location.json` 是重启后定位新家的文件，即使清理旧备份也要保留。新位置不可用或定位文件损坏时插件停止初始化并报错，不会静默使用旧目录或创建新身份。迁移失败时仍使用原目录；如目标有未清理的残留，检查后改用另一个空目录。不要让多份 DSH 宿主或独立 CLI 进程同时写入迁移中的目录。

位置记录和实际运行目录都要纳入备份。迁移锁 `home-location.json.lock` 残留时，先确认迁移进程已退出并核查新旧目录，再人工清理锁。

### 备份与更新

| 路径 | 内容 |
| --- | --- |
| `config.json` | 权威配置，可能含视觉 API 密钥 |
| `self/memory.sqlite` | 独立身份、日记、经历、索引、提示表和人格历史 |
| `out/` | 每日日报 |
| `outbox.jsonl` / `acted.json` | 分享与收藏尝试账本 |
| `social-inbox.json` / `social-cursor.json` | 按账号隔离的新消息基线和名单轮转位置 |
| `diary-cards/` | 只使用公开文案排版的日常图卡 |
| `browser/` | 专用浏览器登录态 |
| `duty.log` | 运行日志，超过约 2 MB 轮转到 `duty.log.1` |
| `duty.md` | 可编辑工作章程 |

升级前，先停止插件及其值班进程，确认没有继续写入，再把**整个运行目录**复制到独立备份位置。SQLite 的 WAL 可能包含新记录，不能在运行中只复制主数据库。恢复时仍使用独立的抖音目录。

源码 link 安装更新时，在源码目录执行 `git pull --ff-only`，再重启 DSH；有本地修改时先整理改动。运行数据不在源码目录，更新代码不需要重建人格。你改过的 `duty.md` 不会直接覆盖，新章程另存为 `duty.md.new`，由你合并。

需要从命令行查看时，先把下面的示例路径替换为设置页显示的**实际运行目录**：

```powershell
Set-Location -LiteralPath 'F:\GitProgramManager\dsh-douyin'
$douyinData = 'D:\你的独立抖音运行目录'
node tools/memory.mjs --home $douyinData status
node tools/memory.mjs --home $douyinData search '手工'
node tools/memory.mjs --home $douyinData history
node tools/memory.mjs --home $douyinData feedback '这里填写真实发生的事件或纠正'
```

这些命令不会启动浏览器或发送消息。`status` 在目录尚无记忆库时会初始化独立身份，`feedback` 会写入记录，所以不要用猜测的路径，也不要指向 B 站目录。`reindex` 只重建派生检索索引，不能修复损坏的原始数据库。

## 8. 常见问题

| 现象 | 处理 |
| --- | --- |
| 设置里没有「刷抖音」 | 检查安装的宿主 profile，完全退出并重新启动 DSH |
| `dsh` 命令找不到 | 使用 DSH 的命令行入口或实际 `dsh.cmd` 完整路径 |
| 提示 `node:sqlite` 不可用 | 检查实际执行插件/MCP 的运行时，升级终端 Node 不一定影响桌面版 |
| 点运行立即结束或提示模型不可用 | 查看 `duty.log`，检查任务 profile、模型登录/API 配置及高级里的 dsh 路径 |
| 搜索、关注或截帧失败 | 先在专用窗口确认登录；遇验证、掉登录或限制时停止，处理后再手动运行 |
| 提示旧版浏览器账本无法确认实例 | 关闭之前打开的抖音专用浏览器，再点「登录抖音」；升级后不会扫描并接管其他插件的浏览器 |
| 扫码窗口消失或显示已关闭 | 重新点「登录抖音」；登录检查保持可见，浏览器错误会显示在设置页 |
| OCR 没识别出内容 | 检查 Windows 语言包；纯画面可能需要可选视觉模型；没有看清内容就不推荐 |
| 无法唯一确认私信会话的主页和昵称 | 此处尚未输入或发送文字。名单主页末尾的 `?from_tab_name=main` 等参数会自动去除，不影响对象识别；查看补充原因：私信面板、标题主页/昵称、输入框和消息列表是否可识别。新版兼容同一人的头像/昵称重复链接，并短暂等待窗口加载；页面仍不支持时停止，不绕过收件人核验 |
| 日记没有每天自动出现 | 确认定时已设、DSH 保持运行，并检查日志；没有真实经历时不会硬造收获 |
| 人格证据失效或提示要重新读取 | 核查被更正的来源，由模型解释并修订人格后取得新上下文，保留历史 |
| 配置、数据库或发送账本损坏 | 保留原文件和日志，停机备份后修复或恢复；不要删除记忆库、清空账本来重试 |
| 发送结果不明或信箱锁残留 | 先核实真实页面和进程状态，再按 [恢复说明](memory.md#维护与恢复) 处理 |

开发时运行 `npm test`、`npm run check`、`npm pack --dry-run`，这些检查不访问真实账号。`tools/selftest.mjs` 会访问抖音，不属于离线验证。
