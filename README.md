# 抖音大肥鱼 · dsh-douyin-scroll

一个有独立记忆、可逐步调整人格的 DSH 抖音插件。基于 Xia28zhi 的 dsh-douyin-scroll 1.4.14 扩展，沿用 MIT 许可证；当前源码版本为 2.0.0，尚未发布 npm 软件包。

[运行指南](docs/running.md) · [源码仓库](https://github.com/TianmuTan/dsh-douyin) · [工作流程](docs/architecture.md)

抖音鱼和 B 站鱼分别成长：不导入 B 站人设、日记、亲戚、账号或运行文件。两边可以使用同一种基础模型，各自保存经历与人格。

## 记忆怎么工作

**长期经历库 → 按话题检索 → 小提示表 → 结合人格行动 → 新经历归档 → 有依据地修订。**

- 长期库：SQLite 保存经历、日记、认识和亲戚偏好，分块后建立 FTS5 索引；旧日记也能被检索。
- 按需读：中文双字词、英文词和 BM25 排序，返回相关片段及版本来源，不在每轮加载全部历史。这是词法检索 RAG，尚未使用向量或 embedding API。
- 小提示表：AI 自行维护，最多 8 行、每行 180 字、合计 1000 字；带来源和 1–30 天有效期。
- 人格：名字、表达、兴趣、习惯、作息偏好可以调整，必须有经历来源、理由和预期版本。历史保留，矛盾可以修订。
- 行动前读自己：挑选视频、写草稿、报告和日记要求用途匹配的当前人格上下文。人格或证据发生变化，重新读取。
- 唤醒词保持简短；默认人格上下文的 JSON 不超过 5000 字符。需要更多信息再检索、阅读原文；这不是整轮总 token 上限。

这里的成长指持续保存、检索和修订认识，不涉及模型权重训练，也不能保证模型每次理解都正确。

## 当前功能

| 功能 | 状态 |
| --- | --- |
| 搜索、关注、热榜、指定博主、可选推荐流 | 已有浏览器适配，需登录后实机验证 |
| 视频截帧、Windows OCR、可选视觉模型 | 已实现；取得可读画面证据后才能挑选 |
| 独立日记、RAG、人格版本、小提示表 | 已实现，提供离线测试与本地查看工具 |
| 昨日回顾 | 每轮检查北京时间昨天，按日期找经历后补写 |
| 亲戚称谓、明确喜好、偏好记忆 | 已实现；名单由监护人维护 |
| 按偏好选择分享对象 | 模型可向允许的目标逐条写草稿；不是无条件群发 |
| 评论、私聊/群视频卡片分享、收藏 | 宿主执行，默认不自动操作账号，需配置及审核 |
| 抖音私人聊天收集、自动回复 | 尚未实现，不宣称已经读取亲戚对话 |
| 抖音每日图文日记、生图及发布 | 尚未实现；现在仅保存最多 280 字的公开文字草稿 |

私聊和群分享目前只发送视频卡片，不会发送草稿正文。评论目标使用监护人配置的单一昵称；尚无一条评论同时真 @ 多位亲戚的实现。

## 安装到 DSH

需要 Node.js **22.16+**（建议 24 LTS，含 node:sqlite）、DSH ≥ 0.1.7，以及已安装的 Edge 或 Chrome。桌面版还需要其实际运行时支持 node:sqlite。浏览器不额外下载；OCR 依赖 Windows 系统语言包。

本地开发安装（profile 换成你实际使用的名称）：

~~~powershell
dsh plugin --profile desktop add link:F:\GitProgramManager\dsh-douyin
~~~

重启 DSH，进入「设置 → 刷抖音」。先配置基础模型使用的 headless profile，登录抖音，再自行决定是否做浏览器自检及跑一轮。打开设置和查看记忆不会自动启动浏览器。

在「记忆与成长」查看独立人格、版本、检索日记和提交监护人反馈。亲戚每行：

~~~text
姑姑 | 亲戚的精确抖音昵称 | 喜欢摄影和手工
叔叔 | 另一位亲戚的精确抖音昵称 | 喜欢编程
~~~

称谓和喜好用于理解关系，发送权限另设。私聊/群须开启并填写精确白名单；空名单或 * 不会授权。建议保留默认逐条审核。自动评论还需开启单独开关、填写目标并遵守配额。AI 不能改监护人、亲戚名单、账号、白名单、审核和额度。

每天固定时间可触发一轮，同时完成昨日回顾；DSH 需要保持运行，机器需要开机。安装本身不会开启定时，也不是操作系统常驻服务。

## 数据与本地检查

默认数据目录为 $DSH_HOME/douyin-duty/，未设置 DSH_HOME 时使用 ~/.dsh/douyin-duty/。宿主提供自定义家目录函数时，以设置页显示的路径为准。运行数据不写入源码目录。

~~~text
douyin-duty/
  config.json          监护人配置（可含视觉 API 密钥）
  self/memory.sqlite   独立人格、日记、经历、索引、提示表
  out/                 日报
  outbox.jsonl         分享草稿与发送状态
  acted.json           收藏尝试账本
  browser/             专用浏览器登录态
  frames/              临时截帧
  duty.md              自定义工作章程
~~~

只检查本地记忆，不打开浏览器：

~~~powershell
node tools/memory.mjs --home "独立抖音运行目录" status
node tools/memory.mjs --home "独立抖音运行目录" search "最近为什么喜欢手工"
node tools/memory.mjs --home "独立抖音运行目录" history
node tools/memory.mjs --home "独立抖音运行目录" feedback "这是监护人提供的经历或纠正"
~~~

数据库损坏时不会静默重建人格。备份请先停止插件及其值班进程，再复制整个运行目录；不要只拷贝仍在写入的 SQLite 主文件，WAL 可能含未合并记录。运行目录、登录态与家庭日记不要放进公开仓库。

## 开发与验证

~~~powershell
npm test
npm run check
npm pack --dry-run
~~~

测试使用隔离的临时目录，不访问抖音、不发送消息，也不消耗模型 API。浏览器、真实页面、DSH UI 和模型行为仍需安装后单独验证。tools/selftest.mjs 是会连接抖音的实机检查脚本，不属于离线测试。
